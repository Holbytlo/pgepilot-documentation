# 13 -- Connector Cache & Budget Strategy

> How PgePilot protects external API rate limits via connector self-governance: caching, budgets, and per-connector enable/disable.
> Last updated: 2026-04-04

---

## Overview

PgePilot collects data from external APIs (GoodWe, SolaX, SmartBox) with strict rate limits. The connector self-governance system prevents API exhaustion through:

1. **Enable/disable flags** -- per connector, per task type (realtime, backfill)
2. **API response cache** -- avoid duplicate calls for the same data
3. **Dynamic cache TTL** -- runtime-tunable per method, no redeploy needed
4. **Rate limiter** -- tracks API usage against daily/hourly budgets
5. **Budget-aware task generation** -- tasks are not generated for disabled connectors

## ConnectorBudgetTrait (PHP)

Shared PHP trait used by all connector classes. File: `src/Specific/Connectors/ConnectorBudgetTrait.php`

### Methods

| Method | Purpose |
|--------|---------|
| `isEnabled(taskType)` | Reads `connector_config.realtime_enabled` / `backfill_enabled` |
| `canAfford(taskType)` | Checks API rate limiter budget |
| `getBudgetInfo()` | Returns dashboard data for UI |
| `getCached(key)` | Reads from `api_response_cache` table |
| `setCache(key, data, ttl)` | Writes to `api_response_cache` table |
| `getCacheTtl(methodName)` | Reads dynamic TTL from `connector_cache_config` table |
| `isCacheEnabled()` | Checks if caching is active for this connector |

### Usage in Connectors

```php
// Example: SolaxCloud.php
public function getRealTimeData($sn) {
    if (!$this->isEnabled('realtime')) return null;

    $cacheKey = "solax:getRealTimeData:{$sn}";
    $cached = $this->getCached($cacheKey);
    if ($cached) return $cached;

    if (!$this->canAfford('realtime')) throw new RateLimitException();

    $data = $this->callApi('/getRealtimeInfo', ['sn' => $sn]);
    $this->setCache($cacheKey, $data, $this->getCacheTtl('getRealTimeData'));
    return $data;
}
```

## Two-Tier Cache Architecture

| Layer | What it caches | Key format | TTL | Owner |
|-------|---------------|------------|-----|-------|
| **Connector cache** | Raw API response | `{connector}:{method}:{params}` | 300s (RT) / 86400s (historical) | Connector (SolaxCloud, GoodweSems) |
| **Application cache** | Processed health result | `rt:{cpCode}` | 300s | TaskController (for HC reads) |

### How Health Check Uses Cache

```
Health Check task for plant X:
  1. Check connector.isEnabled('realtime') → skip if disabled
  2. Check application cache rt:{code} → use if fresh
  3. If no app cache: check connector cache → use if fresh
  4. If no connector cache: make API call → store in both caches
  5. Evaluate health from cached/fresh data
  → Result: HC for 15 SolaX plants = 0 extra API calls (all from cache)
```

## Task Generation Decision Chain

Every task goes through this chain before execution:

```
1. task_definitions.active = 1?
   → NO: task not generated by JobManager

2. connector_config.realtime_enabled (or backfill_enabled)?
   → NO: task variant not generated by TaskManager

3. plants_action.collect_data (or backfill_data) = 1?
   → NO: task skipped by TaskController

4. connector.isEnabled(taskType)?
   → NO: return skipped (ConnectorBudgetTrait)

5. connector.getCached(key)?
   → YES: return cached data (0 API calls)

6. connector.rateLimiter.canCall()?
   → NO: throw RateLimitException

7. → Make API call → store in cache → return data
```

### plants_action flags (pgepilot DB)

| Column | Default | Purpose |
|--------|---------|---------|
| collect_data | 1 | Enable/disable realtime collection for this plant |
| backfill_data | 1 | Enable/disable backfill for this plant |
| check_health | 1 | Enable/disable health check for this plant |

## Budget Tracking

### api_usage table (pgepilot DB)

Tracks every API call with timestamp for rate limiter.

- Cleanup: cron at 03:25 daily, DELETE rows > 30 days
- Query: `SELECT COUNT(*) FROM api_usage WHERE connector='GOODWE_SEMS' AND ts > NOW() - INTERVAL 1 HOUR`

### ApiRateLimiter.php

- Per-connector budget logic
- Reads from api_usage
- Returns canCall() boolean
- Throws RateLimitException when budget exhausted
